
# Travel Compass

Travel Compass — веб-приложение на Python и FastAPI для подбора стран для путешествий на основе предпочтений пользователя.

## Возможности

Приложение позволяет:
- Просматривать список доступных направлений.
- Получать информацию о конкретной стране.
- Подбирать до пяти направлений по бюджету, континенту, месяцу поездки, климату, интересам и типу отдыха.
- Рассчитывать рейтинг соответствия от 0 до 100 баллов.
- Показывать причины рекомендаций.

Бюджет и континент используются как фильтры. Остальные критерии влияют на рейтинг.

Данные о странах являются учебными оценками и не заменяют актуальные туристические рекомендации.

## Технологии

- Python 3
- FastAPI
- Uvicorn
- Pytest
- HTTPX

## Установка

Откройте терминал в папке проекта.

Установите зависимости приложения:

```bash
python -m pip install -r requirements.txt
```

Для разработки и запуска тестов установите дополнительные зависимости:

```bash
python -m pip install -r requirements-dev.txt
```

## Запуск приложения

Для разработки:

```bash
python -m uvicorn app_final:app --reload
```

Для обычного запуска без автоматической перезагрузки:

```bash
python -m uvicorn app_final:app
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000

Интерактивная документация:

http://127.0.0.1:8000/docs

Для остановки сервера нажмите Ctrl+C в терминале.

## Маршруты API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | /health | Проверка работоспособности |
| GET | /version | Версия приложения |
| GET | /countries | Список направлений |
| GET | /countries/{name} | Информация о стране |
| GET | /recommend | Подбор стран по предпочтениям |

Маршрут /recommend принимает параметры:
- budget — бюджет;
- continent — континент;
- month — месяц от 1 до 12;
- climate — желаемый климат;
- interests — интересы через запятую;
- rest — тип отдыха.

## Тестирование

Для запуска автоматических тестов:

```bash
python -m pytest -v
```

Реализованы тесты:
- Проверка /health.
- Проверка рекомендаций /recommend.
- Проверка ошибки при неправильном месяце.

## Переменные окружения

Приложение поддерживает настройку APP_NAME — название приложения.

Пример указан в файле .env.example:

```text
APP_NAME=Travel Compass
```

Для запуска с другим названием на macOS или Linux:

```bash
APP_NAME="My Travel Guide" python -m uvicorn app_final:app
```

Если переменная не задана, используется название Travel Compass.

Файл .env.example служит образцом и не загружается автоматически. Настоящие секреты нельзя публиковать в GitHub.

## Логирование

Приложение выводит информационные сообщения в терминал.

Например, после подбора стран:

```text
INFO: Подобрано направлений: 4
```

Логи помогают проверять работу приложения и искать ошибки.

## Диагностика ошибок

**No module named uvicorn**

Не установлен Uvicorn. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

**Address already in use**

Порт 8000 уже занят. Остановите предыдущий экземпляр Uvicorn с помощью Ctrl+C или используйте другой свободный порт.

**404 Not Found**

Запрошенная страна отсутствует в справочнике.

**400 Bad Request**

Приложение отклонило некорректный параметр, например месяц вне диапазона 1–12.

**Ошибки при тестировании**

Убедитесь, что установлены зависимости из requirements-dev.txt и команда pytest запускается из папки проекта.
