
# Travel Compass

Travel Compass — веб-приложение на Python и FastAPI для подбора стран для путешествий на основе предпочтений пользователя.

## Возможности

Приложение позволяет:
- Просматривать список доступных направлений.
- Получать информацию о конкретной стране.
- Подбирать до пяти направлений по бюджету, континенту, месяцу поездки, климату, интересам и типу отдыха.
- Рассчитывать рейтинг соответствия от 0 до 100 баллов.
- Показывать причины рекомендаций.

Бюджет и континент используются как фильтры. Остальные критерии влияют на рейтинг.

Данные о странах являются учебными оценками и не заменяют актуальные туристические рекомендации.

## Технологии

- Python 3
- FastAPI

- Pytest
- HTTPX

## Установка

Откройте терминал в папке проекта.

Установите зависимости приложения:

```bash
python -m pip install -r requirements.txt
```

Для разработки и запуска тестов установите дополнительные зависимости:

```bash
python -m pip install -r requirements-dev.txt
```

## Запуск приложения

Для разработки:

```bash
python -m uvicorn app_final:app --reload
```

Для обычного запуска без автоматической перезагрузки:

```bash
python -m uvicorn app_final:app
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000

Интерактивная документация:

http://127.0.0.1:8000/docs

Для остановки сервера нажмите Ctrl+C в терминале.

## Маршруты API


Приложение предоставляет следующие API-маршруты:

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | Проверка работоспособности приложения |
| GET | `/version` | Получение версии приложения |
| GET | `/countries` | Получение списка всех стран |
| GET | `/countries/{name}` | Получение информации о выбранной стране |
| GET | `/recommend` | Подбор пяти наиболее подходящих стран |


Маршрут `/recommend` принимает следующие параметры:

- `budget` — бюджет: экономный, средний, высокий.
- `continent` — континент: Европа, Азия, Африка, Америка, Океания или любой (значения вводятся строчными буквами).
- `month` — номер месяца от 1 до 12.
- `climate` — климат: жаркий, тёплый, умеренный, прохладный.
- `interests` — один или несколько интересов через запятую: море, история, природа, развлечения, гастрономия, спорт.
- `rest` — тип отдыха: спокойный, активный, смешанный.

В Swagger UI для бюджета, континента, климата и типа отдыха предусмотрены выпадающие списки.

Первый вариант «Выберите из списка» является подсказкой и не считается допустимым ответом. Если пользователь оставит его выбранным, приложение вернёт ошибку `400` с указанием соответствующего поля.


## Тестирование

Для запуска автоматических тестов:

```bash
python -m pytest -v
```

Реализованы 5 автоматических тестов:

1. `test_health` — проверка работоспособности API.
2. `test_recommendations` — проверка получения рекомендаций.
3. `test_invalid_month` — проверка неправильного номера месяца.
4. `test_invalid_budget` — проверка выбора бюджета.
5. `test_other_dropdowns` — проверка континента, климата и типа отдыха.

Последний тест проверяет три разных поля с помощью цикла.

Все 5 тестов успешно проходят локально и в GitHub Actions.


## GitHub Actions (CI)

В проекте настроена автоматическая проверка кода с помощью GitHub Actions.

Файл конфигурации:
`.github/workflows/ci.yml`

Автоматическая проверка запускается:
- При отправке изменений в GitHub (push).
- При создании или обновлении Pull Request.

GitHub Actions выполняет следующие действия:

1. Загружает файлы проекта из репозитория.
2. Устанавливает Python 3.13.
3. Устанавливает зависимости из requirements-dev.txt.
4. Запускает автоматические тесты командой `python -m pytest -v`.
5. Сохраняет основные файлы проекта в артефакт `travel-compass-files`.

Результаты проверок доступны во вкладке Actions на GitHub.

Репозиторий проекта:
https://github.com/JuliyaArkhipova/travel-compass



## Переменные окружения

Приложение поддерживает настройку APP_NAME — название приложения.

Пример указан в файле .env.example:

```text
APP_NAME=Travel Compass
```

Для запуска с другим названием на macOS или Linux:

```bash
APP_NAME="My Travel Guide" python -m uvicorn app_final:app
```

Если переменная не задана, используется название Travel Compass.

Файл .env.example служит образцом и не загружается автоматически. Настоящие секреты нельзя публиковать в GitHub.

## Диагностика ошибок

**No module named uvicorn**

Не установлен Uvicorn. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

**Address already in use**

Порт 8000 уже занят. Остановите предыдущий экземпляр Uvicorn с помощью Ctrl+C или используйте другой свободный порт.

**404 Not Found**

Запрошенная страна отсутствует в справочнике.

**400 Bad Request**

Приложение отклонило некорректный выбор пользователя.

Например:
- В выпадающем списке осталось значение «Выберите из списка».
- Пользователь указал интерес, которого нет в справочнике.
- Пользователь не указал ни одного интереса.

Программа возвращает сообщение с объяснением ошибки.

**422 Unprocessable Entity**

FastAPI автоматически обнаружил некорректный параметр запроса.

Например:
- Месяц меньше 1 или больше 12.
- Месяц указан не числом.
- В выпадающем списке передано значение, которого нет среди разрешённых.


**Ошибки при тестировании**

Убедитесь, что установлены зависимости из requirements-dev.txt и команда pytest запускается из папки проекта.
